## 📌 Sobre a disciplina

A disciplina apresenta os conceitos fundamentais das linguagens de programação e dos compiladores: paradigmas de programação, análise léxica, expressões regulares, autômatos finitos e análise sintática com gramáticas livres de contexto.

---

## 📚 Conteúdo da disciplina

| # | Assunto | Tópicos |
|---|---|---|
| LE1 | Introdução | Paradigmas das linguagens de programação, processo de compilação |
| LE2 | Análise léxica | Tokens, lexemas e classificação |
| LE3 | Expressões regulares | Construção de padrões (REGEx) |
| LE4 | REGEx com Python | Módulo `re`: `search`, `findall`, `sub`, `split` |
| LE5 | Autômatos finitos | AFD e AFN, tabela de transição, quíntupla |
| LE6 | Construção de Thompson | Tradução de expressão regular em AFN |
| LE7 | Transformação AFN → AFD | Construção de subconjuntos |
| LE8 | Análise sintática | Gramáticas livres de contexto, derivações |

---

## 💡 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/carolferreira-dev/c05_lps_e_compiladores.git
   ```

2. Entre na pasta desejada:
   ```bash
   cd "c05_lps_e_compiladores/Feita por mim/Lista de Exercícios 4"
   ```

3. Execute o programa:
   ```bash
   python exercicio_1.py
   ```

> Os arquivos `.jff` abrem no JFLAP. Cada um tem uma imagem (`.jpg` ou `.png`) com o diagrama do autômato.
